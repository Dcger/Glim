# Glim

本项目主要由 AI 辅助开发（Vibe Coding）实现。

<p>
  <img src="docs/lockscreen.jpg" width="260" alt="锁屏效果" />
</p>

Glim 是一款以手机锁屏为入口、由用户兴趣和可信资料驱动的日常探索应用，通过定期呈现图文、声音与可立即实践的小任务，让知识自然融入生活，激发对周围世界的好奇与观察。

首次打开应用即可浏览「听音乐」和「光与影」的内置卡片，试听合成音、查看概念解释，或把当前卡片设为锁屏壁纸。

在「主题与资料」里可开关、新建主题，记录本地背景，登记书籍或视频等资料。添加卡片时可填写原文引用与概念，并选填小任务、图片和音频。壁纸用上方图片与下方渐变文字排版。无图时显示内置背景，声音在应用内点播。

卡片和配置存储在设备上。可以手动添加卡片，也可以把 Agent 根据你提供的资料生成的卡片批量导入。

## 管理卡片

在「主题与资料」中打开某个主题的「管理卡片」，可查看标题列表、添加卡片或批量删除。标题右侧用绿色「图」表示有配图，红色「音」表示有音频，灰色表示缺少对应附件。点标题即可编辑单张卡片。「发现卡片」预览下方也有「编辑」和「删除」入口。有配图的卡片可用「保存图片」保存原图。

列表左侧勾选框控制卡片是否参加发现浏览和锁屏轮换。可在本主题的卡片管理页全部启用或全部停用。主题关闭时，该主题的所有卡片暂时退出轮换。点「批量删除」后，可在原列表勾选要删除的卡片，图、音标记仍然可见。确认删除后回到卡片启用状态。

编辑页在字段旁显示「标题」「描述」等标签，有配图时显示缩略图。编辑页可通过系统文件选择器保存原附件，也可以更换或移除附件。删除卡片会将其移出该主题和壁纸轮换。

## 锁屏记录与切换方式

在「发现卡片」顶部的「最近锁屏」查看最近 5 次成功换图。点选记录可打开对应卡片、保存当时的合成锁屏图，或把这张图重新应用。卡片删掉后，记录中的快照仍可查看和保存，直到被更新的记录替换。升级前的最近一条记录可从现有卡片重新生成图片。

预览下方的「下一张」「设为锁屏」和「发现浏览顺序」可直接操作。「发现浏览顺序」控制「下一张」。「锁屏轮换方式」控制自动轮换。两项可以分别选顺序或随机。顺序按卡片列表循环，随机在一轮内遍历已启用的卡片。有多张卡片时，随机不会连续两次选中同一张。升级时，两项各自沿用旧版的选择。

## 批量导入卡片

在「主题与资料 → 资料与备注」顶部点「添加资料」，可添加单份资料，也可在系统文件选择器里勾选多份 PDF 一次导入。同一主题内已登记的文件和内容相同的 PDF 会跳过，导入结果会显示新增、重复和失败的数量。资料名默认填为文件名，可在编辑时修改。

「删除资料」支持多选，单份资料的编辑页也有删除入口。删除资料会解除卡片上的资料关联。可在「资料与备注」底部删除整个主题及其中的卡片和资料记录。设备上的原文件会保留。

打开主题的「添加卡片」，选择「批量导入卡片（可由Agent辅助生成）」。第一步选择资料、备注和已有卡片，这些信息均为可选。可以在这一步直接添加资料，新增的资料会自动选中。第二步点「点击唤起Agent或复制提示」，可分享给已安装的 AI 应用或复制提示。所选 PDF 会随分享附送。

第三步用「导入 ZIP / JSON 文件」或「粘贴卡片 JSON」导入已有内容。审阅时可预览媒体，并全选或取消全选能导入的卡片。遇到未知资料 ID，点「匹配资料」为每个 ID 选择当前主题中的对应资料，同一批里所有使用该 ID 的卡片都会更新，原文位置会保留。也可以选「导入时移除此关联」，保留卡片内容和概念解释。处理完成后点「导入选中卡片」。

批量导入页中选完给 Agent 的资料并点「完成」，App 会检查已选 PDF。文件被移动或失去访问权限时，可在提示里直接「重选 PDF」。重新关联保留资料 ID、标题、链接和卡片引用。已记录文件指纹时，新位置里的 PDF 需要与原内容一致。

「选择已有卡片」使用和卡片管理相同的「图／音」标记，可全选或取消全选。资料选择和批量删除资料也支持全选。所选卡片的文本、引用和概念会加入提示作为参考。勾选「让Agent同时更新选中的卡片」后，提示也会附上卡片 ID 和更新规则。返回包中带 `cardId` 的条目会按 ID 更新当前主题已有卡片。更新项默认不勾选，导入时需确认。更新保留卡片的位置、启用状态和历史，并使用返回的 `title` 和 `body`。省略 `task`、`image`、`audio` 会分别保留旧内容，空字符串会清除该项。省略全部三个资料字段 `sourceIds`、`citations` 和 `concepts` 会保留现有引用及概念，提供其中任一字段会使用本次提交的完整引用与概念。新增卡片省略 `cardId`。

编辑页可选「保存并显示在发现页」，保存当前修改并直接打开这张卡的壁纸预览。可从该预览手动设为锁屏，卡片的自动轮换资格仍由主题和卡片的启用状态决定。

```json
{
  "cards": [
    {
      "title": "逆光里看叶脉",
      "body": "叶片透光时，叶脉和薄的叶肉形成明显对比，分叉更容易观察。",
      "task": "举起一片落叶，对着明亮的天空看它的叶脉。"
    }
  ]
}
```

ZIP 的大小上限为 64 MiB、条目上限为 256，卡片 JSON 长度上限为 65,536 字符。标题、正文为必填，小任务可省略。标题、正文和小任务的长度上限分别为 42、155 和 70 个字符。同一主题内标题和正文都相同的卡片只会入库一次。

### 带原文位置和概念解释的卡片

从 Agent 提示的「所选资料」清单中复制应用资料 ID。卡片的 `citations` 列出支持正文的原文位置，可以引用不同章节和多份资料。每条引用的 `sourceId` 和 `locator` 都必填，可把便于搜索的短引文附在 `locator` 内。用「PDF 第 23 页（从文件第一页起数）」标明文件页序后，正文和概念的引用按钮都可在应用内跳到那一页。每个 `concepts` 条目必填非空的 `term`（概念名）和 `explanation`（解释），并可单独列出 `citations`。使用了某份资料、暂时没有精确定位时，把其 ID 写入 `sourceIds`。这三个字段任一出现，资料就按卡片解析，空数组表示显式不关联该类资料。三个字段都缺省的旧格式卡片沿用本批选中的资料。

```json
{
  "cards": [
    {
      "title": "沿边看光",
      "body": "改变视线与光源的夹角，观察同一表面的亮区怎样移动。",
      "sourceIds": [],
      "citations": [
        {"sourceId": "实际资料ID", "locator": "光的反射一节，书页 12"},
        {"sourceId": "实际资料ID", "locator": "观察角度一节，图 3.1"}
      ],
      "concepts": [
        {
          "term": "镜面反射",
          "explanation": "表面会把来自某个方向的光反射到相应方向。移动视点时，能看到高光的位置也会改变。",
          "citations": [
            {"sourceId": "实际资料ID", "locator": "光的反射一节，书页 13"}
          ]
        }
      ]
    }
  ]
}
```

详情里可以展开任意概念，查看解释和对应原文位置，也可打开资料后按章节、页码或图号查找。手动添加或编辑卡片时，可在「原文引用与概念」维护这些内容。单卡最多 10 个概念，卡片正文和每个概念各最多 12 条引用。原文位置最多 320 字，概念名及解释分别最多 80 和 900 字。

### 导入带图片和音频的卡片

在「批量导入卡片」里点「导入 ZIP / JSON 文件」。把 UTF-8 编码的 `cards.json` 放在 ZIP 根目录。每张卡片可以通过 `image` 和 `audio` 指向包里的文件，路径区分大小写。两个字段都可以省略。

```json
{
  "cards": [
    {
      "title": "听两种音色",
      "body": "两个音的音高相同，听起来仍然可能不同。",
      "task": "听一遍录音，试着描述第二个音的质感。",
      "image": "media/timbre.png",
      "audio": "media/timbre.wav"
    }
  ]
}
```

从包含 `cards.json` 和 `media/` 的目录打包，避免多一层文件夹。

```sh
zip discovery-cards.zip cards.json media/timbre.png media/timbre.wav
```

图片支持 JPEG、PNG、WebP，单张最大 12 MiB。音频支持 MP3、M4A、WAV，单条最大 24 MiB。ZIP 以及解包后的媒体总量各自最大 64 MiB。审阅时可看图、试听和取消勾选。确认后，App 会保存选中卡片引用的媒体，原 ZIP 移动或删除后仍可使用。图片用于锁屏，音频在 App 中点播。

一张配图铺满整张锁屏。Agent 提示按手机屏幕比例给出整张配图的像素尺寸，例如高 2400 × 宽 1080。按普通手机壁纸构图，图片下方留给 App 叠加半透明渐变和卡片文字。比例相符的图片完整显示，其他比例的图片按中心裁切以铺满屏幕。

## 导出数据

在「主题与资料 → 导出数据」确认连同资料原文件一同导出，然后选择 ZIP 的保存位置。ZIP 包含 `data.json`（主题、资料、卡片、引用、轮换设置和最近锁屏记录）、`assets/`（可读取的 PDF、配图及音频）、`recent-locks/`（最近锁屏快照）及 `manifest.json`（格式版本、导出时间、读取失败的附件）。JSON 内的附件路径相对于 ZIP 根目录。内置合成音仍以 `sample` 标记。

在另一台手机安装 Glim 0.2.20 或以后版本，复制整个备份 ZIP，进入「主题与资料 → 导入备份」并选择文件。恢复会替换当前主题、卡片、资料、轮换设置和锁屏历史。0.2.19 导出的 ZIP 可直接使用。应用中的 Agent 卡片导入使用独立的 `cards.json` 格式。

## 构建

用 Android Studio 打开本目录并使用 JDK 17 或兼容版本、Android SDK Platform 35 和 Build Tools 35.0.0。使用 Gradle 8.11.1 或兼容版本同步。可在项目根目录执行：

```sh
./gradlew :app:assembleDebug
```

调试包生成在 `app/build/outputs/apk/debug/app-debug.apk`。应用最低支持 Android 7.0（API 24）。

## 验证

推送到 GitHub 前先完成 Android 构建和测试。运行 `bash tools/check-core.sh` 可用 JDK 检查主题过滤、预览遍历、轮换与时间记录。此检查独立于 Android SDK。

在 Android Studio 模拟器中启动应用，滚动到「下一张」并连续点击，检查页面是否留在当前滚动区域。操作主题开关，添加一张带本机图片的卡片并试听内置音频。关闭并重开应用确认新内容仍在。选择「设为锁屏」后，用模拟器锁屏确认图片和底部文字的位置，并检查桌面壁纸。

### 锁屏换图测试

```sh
adb logcat -v time -s Glim
```

日志中的 `SCHEDULED applied` 和 `MANUAL applied` 分别对应常规自动轮换和手动换图。若要检查 Android 记录的近期进程退出原因（Android 11 及以上），可用 `adb shell dumpsys activity exit-info dev.discovery.wallpaper`。

开启「自动更换锁屏」后，App 使用可在待机时唤醒的一次性系统闹钟。每次成功设置锁屏后，从实际完成时间开始计算下一个间隔。系统省电或厂商后台管理可能推迟闹钟。最近任务清理若触发强行停止，再打开 App 会恢复排程。

```sh
adb shell dumpsys alarm | grep -F 'dev.discovery.wallpaper.ROTATE_LOCK'
```

真机测试时先开启自动更换，选择 15 或 30 分钟，把 App 留在后台并锁屏，通过日志和「最近锁屏」核对每次实际换图时间。常规轮换默认关闭，开启后默认间隔为 30 分钟。

- [Doze and App Standby](https://developer.android.com/training/monitoring-device-state/doze-standby)
